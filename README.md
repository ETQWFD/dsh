# DSH - DeepSeek增强助手

> 让DeepSeek拥有眼睛和记忆的浏览器插件

## ✨ 功能特性

### 🎬 视频解析AI视觉
- 支持B站、YouTube、抖音、腾讯视频、优酷、爱奇艺等主流视频网站
- 自动解析视频标题、UP主、时长、简介等信息
- 一键将视频内容摘要发送给AI，让AI能"看到"视频
- 通用网页视频解析，支持几乎所有网站

### 🧠 跨对话长期记忆
- 持久化存储重要对话信息，跨对话不遗忘
- 记忆面板可查看、添加、删除记忆
- 新对话自动提示已加载记忆
- 本地存储，隐私安全

### 🗑️ 对话回收站
- 右键左侧对话列表，选择"删除对话"
- 删除的对话不会真正消失，而是移入回收站
- 回收站可一键恢复误删的对话
- 支持永久删除释放空间

## 📦 安装方法

### 方法一：Chrome商店安装（即将上线）
```
打开Chrome商店 → 搜索 DSH → 点击安装
```

### 方法二：开发者模式加载（当前可用）
1. 下载本仓库代码到本地
2. 打开Chrome浏览器，地址栏输入 `chrome://extensions/`
3. 开启右上角"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本文件夹（dsh目录）
6. 安装完成！打开 https://chat.deepseek.com 即可使用

### 方法三：一键安装命令
```bash
# 克隆仓库
git clone https://github.com/ETQWFD/dsh.git

# 然后按方法二加载
```

## 🚀 使用说明

### 解析视频
1. 打开DeepSeek网页版
2. 在输入框粘贴视频链接（B站/YouTube等）
3. 点击输入框右下角的"🎬 解析视频"按钮
4. 自动解析视频信息并填入输入框
5. 发送给AI即可讨论视频内容

### 管理记忆
1. 点击右上角"🧠 记忆"按钮打开记忆面板
2. 点击"添加记忆"记录重要信息
3. 新对话开始时自动提示已加载的记忆

### 对话回收站
1. 在左侧对话列表上**右键点击**
2. 选择"🗑️ 删除对话（移入回收站）"
3. 点击左下角"🗑️ 回收站"查看已删除的对话
4. 点击"恢复"找回误删的对话，或"永久删除"彻底清除
