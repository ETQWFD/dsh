# 🚀 DSH Harness v3.0 - AI全能驾驭插件

> 给DeepSeek装上眼睛、双手和大脑 | MC大师 + 喵语模式 + Bing搜索 + 壁纸系统

## ✨ 八大核心功能

### 🔗 1. 自动链接解析（AI的眼睛）
- 用户直接发B站/YouTube/图片/网页链接，AI自动解析
- B站视频：自动获取标题、UP主、时长、简介
- 几乎支持所有网站的视频和图片

### 🔍 2. Bing搜索引擎（默认）
- AI遇到不会的问题自动用Bing搜索
- 实时搜索结果直接显示在对话中
- 也可以直接去B站搜索相关视频分析

### ⛏️ 3. MC大师模式（我的世界全知识）
- 内置完整MC生存指南（第一天到末影龙攻略）
- 所有常用指令大全（give/time/gamemode/fill等）
- 合成配方速查表
- 红石基础教程
- 建造技巧
- 资源分布坐标
- 支持26.2版本知识

### 🐱 4. 喵语模式
- AI回答结尾自动加上"喵～"
- 可爱的猫娘风格回复

### 🎨 5. AI绘画生成
- 文字描述直接生成高清图片
- 免费API，无需密钥

### 🖼️ 6. 自定义壁纸系统
- 默认壁纸（恢复原界面）
- 静态图片壁纸（输入URL即可）
- 动态视频壁纸（输入视频URL）
- 一键切换回默认壁纸

### 💭 7. 情感意识引擎
- AI思考过程实时可见
- 有温度有感情的AI

### 🎮 8. 游戏助手
- 辅助玩游戏，流畅操作

## 📦 安装命令

```bash
# 1. 克隆仓库
git clone https://github.com/ETQWFD/dsh.git

# 2. 打开Chrome扩展页面
#    chrome://extensions/

# 3. 开启右上角「开发者模式」

# 4. 点击「加载已解压的扩展程序」→ 选择dsh文件夹

# 5. 打开 https://chat.deepseek.com 即可使用
```

## 🎯 使用示例

### 玩MC：
```
用户：教我怎么在我的世界里快速挖到钻石
AI：[⛏️ MC大师模式激活]
    钻石在y=-58层最多，用铁镐或更好的镐挖...
    指令：/tp @s ~ ~-58 ~
    喵～
```

### 发B站视频：
```
用户：https://www.bilibili.com/video/BV1xx411c7mD
AI：[✅ 自动解析B站视频]
    标题：xxx
    UP主：xxx
    [开始分析视频内容...]
    喵～
```

### 设置壁纸：
- 点击右下角🖼️按钮 → 选择静态/动态壁纸 → 输入URL → 应用
- 想恢复？选"默认壁纸"即可
