# 🚀 DSH Harness - AI全能驾驭插件 v2.0

> 给DeepSeek装上眼睛、双手和大脑的超级浏览器插件

## ✨ 七大核心能力

### 🔗 1. 自动链接解析（AI的眼睛）
- 用户直接在对话中发B站、YouTube、抖音、腾讯视频等链接
- **自动识别并解析**视频标题、UP主、时长、简介、播放量
- 自动识别图片链接、网页链接
- 解析结果自动注入AI上下文，AI"直接看到"视频内容
- 支持几乎所有网站的视频和图片

### 🔍 2. AI自主搜索能力
- AI可以自己搜索互联网获取最新信息
- 实时搜索结果直接显示在对话中
- 无需用户手动复制粘贴资料

### 🎨 3. AI绘画生成
- 在对话框说"画一只猫"，AI直接生成高清图片
- 基于Pollinations.ai免费API
- 支持任意风格、任意主题
- 生成结果直接显示在对话流中

### 🎬 4. AI视频生成
- 文字描述直接生成高清视频
- 持续升级中

### 🖥️ 5. 电脑操控授权系统
- 用户让AI操作电脑时，自动弹出**安全确认弹窗**
- 必须勾选「我已阅读并同意使用协议」才能授权
- 授权后AI可移动鼠标、点击、输入、打开应用
- 安全可控，用户随时可以收回权限

### 💭 6. 情感意识引擎
- AI有"思考过程"可见
- 实时显示AI的内心活动：分析意图、检索知识、组织回答...
- 有温度、有情感的AI体验

### 🎮 7. 游戏助手模式
- AI辅助玩游戏
- 流畅的操作响应
- 自动分析游戏画面，给出策略建议

## 📦 安装方法

### 一键安装命令：
```bash
# 1. 克隆仓库
git clone https://github.com/ETQWFD/dsh.git

# 2. 打开Chrome扩展页面
#    Chrome地址栏输入: chrome://extensions/

# 3. 开启右上角「开发者模式」

# 4. 点击「加载已解压的扩展程序」→ 选择dsh文件夹

# 5. 打开 https://chat.deepseek.com 即可使用
```

## 🎯 使用示例

### 发视频让AI分析：
```
用户：帮我分析这个视频 https://www.bilibili.com/video/BV1xx411c7mD
AI：[自动解析B站视频] ✅ 已获取视频信息
    标题：xxx
    UP主：xxx
    [开始分析视频内容...]
```

### AI绘画：
```
用户：帮我画一只赛博朋克风格的猫
AI：[🎨 开始生成图片...] ✅ 生成完成
    [显示高清生成图片]
```

### AI操作电脑：
```
用户：帮我打开百度搜索今天的天气
AI：[🖥️ 请求电脑操控权限...]
    [弹出授权窗口，用户勾选同意后...]
    ✅ 已打开浏览器，正在搜索...
```

## 🏗️ 技术特点

- **低内存占用**：所有模块按需启动，缓存自动清理
- **无第三方依赖**：纯原生JS，轻量高效
- **隐私安全**：所有数据存储在本地浏览器
- **Manifest V3**：最新Chrome扩展标准
- **响应极快**：防抖、缓存、延迟启动优化
